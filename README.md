# E-commerce ERP System (VBA)

This side project has been in development since 2019, originally built to manage CRM data across three major e-commerce platforms — **Yahoo, Ruten, and Shopee**. It was initially coded entirely in **Excel VBA**, and has since been refactored into a Streamlit app:

👉 **[e-commerce-ERP-system-streamlit-app](https://github.com/lee2nd/e-commerce-ERP-system-streamlit-app)**

## Key Features

- Automated computation of key metrics
- Automated separation of summary information into two parts
- Thoughtful UX design
- Concise, user-friendly UI
- Data visualization
- Customizable dropdown lists

## Key Challenges

- **Concurrent usage**: Supporting two users working simultaneously required splitting summary data into separate A/B sections to avoid conflicts
- **Frequent updates**: Platform fee ratios needed frequent updates due to high-frequency changes across platforms
- **Zero-downtime upgrades**: Users couldn't tolerate long downtime, so updates had to be fast and non-disruptive

## Background

The initial build took about one month to complete, and the project has generated approximately **NT$20,000** in extra income to date.

This project was designed and built entirely by myself, drawing on VBA coding techniques I first learned during my time at **ACNielsen**. Special thanks to my manager, **Lavan**, for the opportunity and support.
